# Disable Prisma Language Server warnings
# Add this to your VS Code User Settings (Ctrl+Shift+P > "Preferences: Open User Settings (JSON)")

# Or disable the Prisma extension temporarily:
# 1. Go to Extensions (Ctrl+Shift+X)
# 2. Search "Prisma"  
# 3. Click "Disable" on Prisma extension
# 4. Reload VS Code
